隐私政策 / Privacy Policy

最后更新：2026-10-30

1. 这个应用是什么

“Local Drive Sync”是仅供所有者本人使用的个人 OAuth 客户端（Google Cloud 项目中的一个 Desktop 客户端）。不对外提供服务、不注册用户、不在任何应用商店发布。

2. 处理哪些数据

经 Google OAuth 授权后，可以访问所有者本人 Google Drive 中的文件（读取、上传、修改、删除、移动）及文件元数据（名称、大小、修改时间、共享设置）。不访问其他 Google 服务。

3. 数据如何保存

  • OAuth 访问令牌与刷新令牌保存在所有者本机配置文件（权限 0600），不发送到第三方服务器。
  • 文件内容仅在所有者本机与 Google 服务器之间直接传输。
  • 本地缓存仅存于本机，按设定的大小与时长上限自动清理。

4. 共享与转让

不向任何第三方出售、出租、共享或转让数据；除所有者主动操作外，不改变文件的共享状态。

5. 保留与删除

撤销授权即失去访问能力；删除本机配置文件即移除令牌。删除的文件进入 Google Drive 回收站，由 Google 的保留策略处理。

6. Google API 服务用户数据政策

对从 Google API 获得的信息的使用遵守 Google API Services User Data Policy，包括 Limited Use 要求。
